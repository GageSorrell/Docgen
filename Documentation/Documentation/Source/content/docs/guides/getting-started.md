## Build a useful first site

Start with the [Introduction](./introduction/) to understand the site structure. Then create a site, add a page, and run the generated workspace checks before publishing.

The site content uses Markdown by default. Add MDX when an article needs an interactive React example or a richer content component. Keep examples close to the explanation that gives them meaning.

## Explore the generated site

The documentation shell provides responsive navigation, a table of contents, canonical URLs, metadata, and a Copy for LLM control on each article. API references are generated from the package entry points listed in the site configuration.

Use the [Customization guide](./customization/) to adjust metadata, navigation, theme tokens, and generated API references.
