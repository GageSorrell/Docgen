## A documentation system with clear boundaries

Sorrell Documentation gives teams a stable place to explain products, publish API references, and keep examples close to the code they describe.

The system separates shared presentation, Astro integrations, and the content owned by each site. This keeps framework-specific behavior at the edge while letting content models and route helpers serve multiple documentation surfaces.

## What a site includes

- Markdown and MDX articles organized into versioned routes.
- Generated API references based on TypeScript package entry points.
- Shared navigation, themes, search, metadata, and publishing configuration.
- Agent-friendly Markdown copies and indexes for site content.

Continue with [Getting Started](./getting-started/) to create and build a site.
